# Белка - Roadmap для Яндекс.Игры

## 📋 Описание проекта

Карточная игра "Белка" для 4 игроков (2v2), популярная в Казахстане. Цель: первыми открыть 12 глаз или взять 120 очков за раздачу.

**Платформа:** Яндекс.Игры (HTML5)  
**Жанр:** Карточная игра, Мультиплеер  
**Технологии:** React, TypeScript, PixiJS, Node.js, Socket.io

---

## 🎯 Фаза 1: MVP Core (2-3 недели)

### Week 1: Игровая логика

#### Deck & Cards
- [ ] Колода 36 карт (6, 7, 8, 9, 10, В, Д, К, Т)
- [ ] Номиналы очков:
  - Туз — 11
  - Десятка — 10
  - Король — 4
  - Дама — 3
  - Валет — 2
  - 7, 8, 9 — 0
- [ ] Постоянные козыри (валеты по старшинству):
  - В♣️ (самый старший)
  - В♠️
  - В♥️
  - В♦️

#### Game State Manager
- [ ] Раздача 8 карт каждому игроку (по 2 карты за раз)
- [ ] Назначение козырной масти (владелец В♣️ в первом коне закрепляет ♣️)
- [ ] Валидация ходов:
  - Обязательно класть масть хода
  - Можно рубить козырем при отсутствии масти
  - Можно слить любую карту
  - **Нельзя сливать туза в неигравшую масть**
- [ ] Определение победителя взятки
- [ ] Переход хода

#### Scoring System
- [ ] Подсчет очков взяток (всего 120 в колоде)
- [ ] Логика открытия глаз:
  - 1 глаз: 60+ очков, козырь у вашей команды
  - 2 глаза: 60+ очков, козырь у соперников
  - +1 глаз: если проигравшие набрали <30 ("спас")
  - Первая раздача: всегда 2 глаза победителю
- [ ] Система шестерок для счета (0→6→12)
- [ ] Детект специальных ситуаций:
  - "Яйца" (60:60) — глаза не открываются
  - "Голая" (120:0) — мгновенная победа
- [ ] Условие победы: 12 глаз

- [ ] Счетчик очков текущей раздачи

- [ ] Анимации:

  - Открытие глаз
- [ ] Подсветка доступных для хода карт
- [ ] Визуальная индикация козырей (рамка/значок)

#### Game Flow
- [ ] Экран главного меню
- [ ] Лобби (ожидание игроков)

- [ ] Игровой процесс:

## 📝 Notes

### Приоритеты разработки
1. **Корректная игровая логика** (самое важное!)
2. **Стабильный мультиплеер** (без лагов и багов)
3. **Интуитивный UI/UX** (легко научиться играть)
4. **Mobile-friendly** (большинство пользователей на телефонах)
5. **Монетизация** (ads + IAP)

### Риски
- Сложность балансировки ботов (AI для игры в Белку)
- Проблемы с синхронизацией в мультиплеере
- Региональные различия в правилах (нужна гибкая настройка)
- Модерация Яндекс.Игры может занять 1-2 недели

### Возможности расширения
- Портирование на VK Play, OK Games
- Мобильное приложение (React Native)
- Интеграция с Telegram Mini Apps
- Киберспортивные турниры
