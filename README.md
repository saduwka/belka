# 🐿 Белка (Belka)

**Белка** — мультиплеерная карточная игра для 4 игроков (2 на 2), популярная в Казахстане. Цель — первыми открыть 12 «глаз» или набрать 120 очков за раздачу. Проект в разработке, целевая платформа — Яндекс.Игры (HTML5).

## 🎯 Правила вкратце

- Колода 36 карт, постоянные козыри — валеты (♣ старший, затем ♠, ♥, ♦).
- Обязательна подстройка под масть хода, можно рубить козырем или сливать любую карту (кроме туза в неигравшую масть).
- Победа при 12 «глазах»; особые случаи — «яйца» (60:60) и «голая» (120:0).

## 🚀 Технологический стек

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **тестирование:** Vitest (юнит-тесты игровой логики)
- **CI:** GitHub Actions
- **Планируется:** PixiJS для рендеринга стола, Node.js + Socket.io для мультиплеера, PostgreSQL + Prisma для статистики и лидербордов, интеграция Yandex Games SDK

## 🗺 Статус разработки

Проект находится на стадии MVP: игровая логика и настольный UI для одиночного/локального режима. Подробный план — в [BELKA_ROADMAP.md](./BELKA_ROADMAP.md), включает мультиплеер, интеграцию с Яндекс.Играми, монетизацию и мобильную адаптацию.

## 🛠 Установка и запуск

```bash
git clone https://github.com/saduwka/belka.git
cd belka
npm install
npm run dev
```

тесты: `npm run test`
